# Layoutização Rio Piranhas

Landing page de apresentação e venda dos ebooks de layoutização da Rio Piranhas para supermercados e farmácias.

## Executar localmente

```bash
python3 -m http.server 8000
```

Depois, acesse [http://localhost:8000](http://localhost:8000).

## Estrutura principal

- `index.html`: página principal.
- `css/rio-piranhas.css`: identidade visual e componentes personalizados.
- `js/rio-piranhas-brand.js`: conteúdo, catálogo, vídeos e personalizações.
- `images/ebooks`: capas dos oito ebooks.
- `videos`: vídeos utilizados na landing page.
